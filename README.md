# spdcOAM
The scripts in this directory compute the spatial mode correlation of the photon pair generated in the process of spontaneous parametric downconversion (SPDC). 

**spdc_walkoff_sim.ipynb** contains the simulation of the orbital angular momentum correlation under the pump walk-off effect. This effect is discussed in detail in [Yang Xu and Robert W. Boyd, "Engineering walk-off-induced orbital angular momentum spectrum in spontaneous parametric downconversion," Opt. Lett. 51, 1804-1807 (2026)](https://opg.optica.org/ol/abstract.cfm?uri=ol-51-7-1804)
